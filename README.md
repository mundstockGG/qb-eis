# QBCore Environment Interaction System

This script allows players to interact with props in the game world. When a player gets near a prop, they can press a key to view a notification with the prop's title and description. The camera smoothly transitions to focus on the prop during the interaction.

## Features
- Dynamic prop spawning based on configuration.
- 3D text display for interaction prompts.
- Smooth camera transitions.
- Customizable notifications with titles and descriptions.

## Installation
1. Add `ensure qb-eis` to your `server.cfg`.
2. Restart your server.

## Configuration
Edit `config.lua` to define props, their spawn locations, and interaction details.
